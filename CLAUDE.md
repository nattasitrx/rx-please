## What the game is
A cute, cooking-game-style pharmacy game in one self-contained file: `index.html` (HTML + CSS + JS, Google Fonts Mali / Sarabun / Pridi / Chakra Petch).
Customers walk in and order medicines; the player prepares them in three zones and taps to hand them over.
- **Tablets:** jar → counting tray → (amber bag for vitamin C, or mortar to crush amlodipine for patients who can't swallow; `rzMortarFill` draws the waiting tablets, mortar glows until crushed).
- **Liquids:** dry syrup → water → shake (sediment returns if left) → label; cough syrup and oral syringe are instant.
- **Cold chain:** fridge → ice-pack box with a cold gauge that spoils.

Levels 1–50 exist in this version (`RZ_LAST=50`, 5 chapters of 10: ปากซอย, ข้างโรงเรียน, ตลาดนัด, ในห้าง, ริมทะเล). After level 50 a "coming soon / ติดตามเวอร์ชันใหม่" card shows. The old hospital OPD pharmacist mode was removed; its last version is kept on branch `archive/opd-mode`.

## Code map (all in index.html)
- Prefix `rz` / `RZ` for everything. Main container `#rz` (`rzEl`) inside `#app` (fixed 1120×630 landscape or 480×900 portrait canvas scaled with `--s`).
- Save: `localStorage['rxplease-rush-v1']` → object `RD` (stars[], best[], wallet, gem, bst{}, up{}, dup{}, gpp{}, cx{}, cxr{}, q{}, w{}, ms{}, life{}, gift{}, bossG{}, seen{}, tutOff, music, fs, hiStart). Always save with `rzSave()` (it also syncs map header pills).
- Debug hook: `window.__rz()` returns the running level state `RZ`.
- Level generator `rzLevel(L, seed)`; unlock schedule `RZ_UNL` (new drugs at L1–8, 14 insulin, 17 crushing, 20 cold eye drops, 23 VIP, 26 chatty customers, 28 four-item orders, 31 rush hour, 33 VIP chatters (always buy, longer chat), 41 hot days). Aspirin EC and the "don't crush" trap/consult popup were removed on purpose (owner felt it broke the flow).
- Systems: shop upgrades `RZ_UP`; drug cost tiers `RZ_DUPN` (buying smarter lowers cost → more profit, not "services"); my-shop extras `RZ_GPP` (the shop already passes GPP from day one; these are beyond-GPP services); codex `RZ_TOPIC` + per-drug facts, +15/+20 coins for reading each card; daily/weekly quests `RZ_QP` and missions `RZ_MS` with claim-all.
- Level events (chapters 4–5): `RZ_LVEVT[L]` → `V.ev` from `RZ_EVT` = rush (gap ×0.75), chatday (chat 36%), vipday (VIP 34%), hot (cold gauge ×0.7, more cold items). Shown as chips on the intro card and icons on the level pill. Bot run (Playwright, 3× time, ~3 taps/s) clears 21–50 with steady time/par ratios.
- Chatty customers (`c.chat={need,buy,taps}`, ~20% of customers from L26, never VIP): bubble shows 💬 + pips; tapping the customer repeatedly (`rzChatTap`, no popup) chats. When done: `buy` → order revealed + bonus tip on payment (`c.tipx`); otherwise thanks + 0/5/10 tip and leaves. Ignored chatters leave on their own with no miss / combo break. Hidden orders never receive items (rzWho/aide/ptph skip `c.chat`). Lines in `RZ_CHATL` / `RZ_CHATBYE`. Quest `chat`, perk `allergy` boosts the chat tip.
- VIP = over-the-top "คุณนาย": `czPerson({...look,vip:1})` draws hat, heart sunglasses, pearls, boa and VIP sash; gold glow + sparkles (`.vip-sp`). `RZ_CROWN` is no longer used.
- Multi-touch: touch taps on jars/slots/customers are handled per finger on pointerup (`rzGameTap`), the follow-up click is ignored via `data-tt`; play area has `touch-action:none`.
- Gems & boosters: `RZ_BST` (calm, ice, shaker, grinder, aide = pharmacy assistant prepares, ptph = part-time pharmacist serves one customer every 15 s, feast), `RZ_MORE` rescue (+3 customers). Gems only from map gift boxes (after levels 4 and 8 of each chapter), first 3★ on boss levels, weekly quest bonus. Never sold for coins. Free trial levels `RZ_TRIAL`.
- Balance (bot-calibrated 2026-11-03, `bot0.py`-style Playwright run at 3× time): coin goal factor `cf` .85 → 1.45 between L12 and L20 (tips/combos pay far above base price); crush counts 4 s in par work; star-time multiplier `km` = 1.12 for L≤10, 1 to L28, down to .72 from L36 (combo goals excluded). Bot time/3★-par by chapter ≈ .65 / .60 / .56 / .52 / .50, coin and other goals aligned.
- Upgrade advice: `rzUpFx(id,lv)` shows before → after values on each shop row (class `rz-upfx`; note `.rz-fx` is the effects layer, don't reuse it). `rzRecUp()` picks one upgrade from what went wrong last level (`RZ_LR` set in `rzEnd`: walkouts by zone, spoiled, misses, failed goal type) plus a base priority; shop shows a ⭐ แนะนำ badge + header; the end card shows `rzRecBox` when failing, or when passing and the advice is affordable (button `upgo` opens the shop highlighting that row).
- Click actions are dispatched by `data-r` names in one big handler: names must be unique (decor uses `decbuy`/`dectog`; `dbuy` is the drug-cost tier buy). A clash once silently broke ลดต้นทุนยา.
- Decor shop (coin sink, cosmetic only): `RZ_DECOR` (bunting, plants, window lights, balloons, cat, OPEN neon, marquee sign, gold shelves; 13,800 coins total) in shop tab `decor` from L12; `RD.dec[id]` 1 shown / 2 hidden; drawn by `rzDecorSVG()` inside `rzScene`.
- Saves are sanitized by `rzClean`/`rzSafeSave` on load and on import (stored-XSS fix); keep new save fields to numbers / short ids.
- Chapter star gates `rzGateNeed(L)` (about 2.15★ per level needed).
- Fullscreen: the splash tap calls `rzFsOn()` on touch devices unless `RD.fs===0` (settings toggle `data-r="fs"`). iPhone Safari has no page fullscreen, so `rzA2hs()` shows an add-to-home-screen guide once (`RD.seen.a2hs`) and in settings. Home-screen app: `manifest.webmanifest` + `icons/` + apple meta tags; `layout()` keeps the canvas inside the safe area (notch). No service worker on purpose, so pushes reach players right away. Guide `rzA2hs()` is an illustrated stepper (`rzPh(scene)` draws SVG phone mock-ups) chosen by `rzEnv()`: Safari 26 (⋯ › Share), older Safari, Chrome iOS, in-app browsers (LINE, Facebook, Messenger, IG, TikTok → open in browser first, shown once per session). LINE is redirected to the external browser at load with `?openExternalBrowser=1` (flag kept in the URL as a loop guard, stripped outside LINE). iOS home-screen apps have separate storage from Safari, so `rzXfer()` moves a save as an `RXP1.<base64 JSON>` code (settings › ย้ายเซฟ; offered on the first home-screen launch via `RD.seen.sa`).
- Analytics: PostHog (US cloud, project 706171, key in `RZ_PH_KEY`); `RZ_PH_HOST` us. Loader + `rzAnInit()` after `rzSave`; `rzA(event, props)` adds hi_level / levels_cleared / stars_total / orient. No names (localStorage id, no cookies, no autocapture, no recordings); IP kept only for province via GeoIP, last octet zeroed by an "IP Anonymization" transformation; PostHog also drops any event whose $host is not nattasitrx.github.io (transformation "Drop events not from the game site": add new domains there if the game moves); settings toggle `data-r="an"` → `RD.an=0` opts out. Events: $pageview, game_enter, level_start, level_end {result pass/fail/quit/restart/closed, stars, time_s, served, missed, walkout_items{drug:n}, spoiled, trashed, chat_buy/chat_bye/chat_ignored, boosters}, unclean_exit {level, level_orient, secs_in_level, secs_since_alive} (sent on the next launch when a level was on screen and not backgrounded when the page died, i.e. an iOS web-process crash/reload; `rzLive`/`rzLiveCheck`, localStorage `rxp-live` heartbeat), codex_read, shop_buy, decor_buy, feedback_click, donate_open, a2hs_step, home_screen_first_launch, fullscreen_toggle, save_code_copied, save_imported, chapter_gate_blocked, reached_end_of_content. Super props: game_v (`RZ_VER`, bump on releases), display, inapp, from_line_redirect. Testing in headless Playwright needs `opt_out_useragent_filter:true` in a test copy (PostHog drops headless traffic).
- Support-the-developer card `rzDonate()` (PromptPay QR embedded, `RZ_PPID` e-Wallet ID copy button). Feedback form link goes in `RZ_FORM` (empty = button hidden).
- Art is mostly inline SVG drawn in code (`czPerson`, `rzOutdoor` map).
- Shop backdrop `rzScene` is Canva art: `art/shop.webp` (source 1776 px wide, rows 0–460, window glass cut to alpha) drawn at 1120 wide and `RZ_SCY`=7 down so the arch clears the HUD; behind the glass sits `art/view{1-5}.webp`, one view per chapter (soi, school, market, mall, beach) chosen by `RZ_SCH` (set from `V.ch` in the play/intro screens, 0 on the splash). - Drug & equipment icons are glossy 3D images made with Canva (style A "clay plastic, kawaii face") in `art/*.webp` (~8 KB each, cropped square, transparent). `RZ_IMG` maps item id → file (`aml~c` → `amlc` powder sachet); `rzArt` returns `rzImgArt` (image + code badge from `RZ_GLY` for colour-blind players, + small `amberbag`/`coolbox` overlay for amber/cold orders). - Performance on iPhone (home-screen app crashed twice in portrait, Nov 2026): keep CSS `filter` and infinite animations few.
