# Rx, Please! · ร้านยาทันใจ

เกมจัดยาสไตล์เกมทำอาหาร ลูกค้าเดินเข้ามาสั่งยา ผู้เล่นนับยาเม็ด ผสมยาน้ำ บดยา และส่งยาเย็นให้ทันเวลา พร้อมเกร็ดความรู้เรื่องการใช้ยา

**เล่นเลย:** https://nattasitrx.github.io/rx-please/
